# iptime-netwatch

**"와이파이는 잡히는데 인터넷이 안 돼서, 결국 공유기 코드를 뽑았다 꽂았다"** 를 대신 해 주는 Mac용 작은 도구예요.

집에 있는 Mac이 10초마다 인터넷이 되는지 살펴보다가, 30초 넘게 끊겨 있으면 ipTIME 공유기를 알아서 재부팅해요. 다 살아나면 휴대폰으로 iMessage도 보내 줘요.

```
2026-10-24 06:05:46	끊김 시작: 상위장비=FAIL DNS=FAIL HTTP=000
2026-10-24 06:06:16	끊김 0분 30초 지속, 공유기 wan=up protocol=ok ..., 재부팅 {"result":"done"}
2026-10-24 06:06:56	복구됨: 총 1분 10초 끊김, 자동 재부팅으로 복구
```

자고 있는 새벽에 끊겨도, 아침에 일어나면 이미 고쳐져 있어요.

---

## 이런 분께 맞아요

- 하루에 한 번꼴로 **와이파이 신호는 멀쩡한데 인터넷만 안 되는** 일이 생긴다
- 그럴 때 **공유기 전원을 껐다 켜면 거짓말처럼 된다**
- 공유기가 **ipTIME**이고, 관리 화면(`192.168.0.1`)이 요즘 나오는 새 디자인이다
- 집에 **늘 켜 두는 Mac**(맥미니, 집에 두고 쓰는 맥북 등)이 있다

자취방이나 원룸처럼 건물 통신사 장비 뒤에 ipTIME을 하나 더 물려 쓰는 집에서 특히 자주 생기는 증상이에요. 원인을 뿌리 뽑지 못해도, 일단 "알아서 껐다 켜 주기"만으로 생활이 꽤 편해져요.

### 이런 경우엔 안 맞아요

- 공유기가 ipTIME이 아니거나, 관리 화면이 예전 스타일(파란 메뉴 화면)인 경우: 공유기에 명령을 보내는 방식이 달라서 동작하지 않아요.
- 와이파이 자체가 끊기는 경우: 이 도구는 "공유기까지는 되는데 바깥 인터넷만 안 될 때"만 손을 대요.
- 집에 Mac이 없을 때가 많은 경우: Mac이 집 와이파이에 붙어 있어야 동작해요.

---

## 어떻게 동작하나요?

```
Mac ──와이파이──▶ ipTIME 공유기 ──▶ (통신사 장비) ──▶ 인터넷
 │
 └─ netwatch가 10초마다 확인
     ① 지금 붙은 공유기가 우리 집 ipTIME인가?   아니면 아무것도 안 함
     ② 1.1.1.1 / 8.8.8.8 에 닿나?               되면 끝
     ③ 두 번 연속 안 되면 "끊김 시작"을 기록하고 원인을 간단히 진단
     ④ 30초가 지나도 안 되면 → 공유기에 로그인해서 재부팅
     ⑤ 다시 되면 → 몇 분 끊겼는지 기록 + iMessage
```

조금 더 자세히 보면:

- **공유기 재부팅**: ipTIME 관리 화면에서 버튼을 누르면 브라우저가 공유기에 보내는 요청을 그대로 보내요. 관리자 계정은 macOS 키체인에 넣어 두고 쓸 때만 꺼내요. 파일이나 기록에는 절대 남지 않아요.
- **우리 집 공유기 알아보기**: 카페 공유기도 ipTIME이면 주소가 똑같이 `192.168.0.1`이에요. 주소만 보고 판단하면 남의 공유기에 내 관리자 계정을 보내게 될 수 있어요. 그래서 공유기 고유의 하드웨어 주소(MAC)까지 맞을 때만 우리 집으로 봐요.
- **잠자기 방지**: 집 와이파이에 붙어 있는 동안만 Mac이 잠들지 않게 해요. 밖에 들고 나가면 평소처럼 잠들어요. 화면은 꺼져도 괜찮아요.
- **무한 재부팅 방지**: 한 번 재부팅하면 30분 동안은 다시 재부팅하지 않아요. 통신사 쪽이 완전히 죽은 날에 공유기만 계속 껐다 켜는 일이 없도록요.
- **조용한 기록**: 정상일 때는 한 줄도 남기지 않아요. 끊겼을 때만 무슨 일이 있었는지 남겨요.

## 설치하기

### 1. 내려받고 설치

```bash
git clone https://github.com/ppower-dev/iptime-netwatch.git
cd iptime-netwatch
./install.sh
```

`~/.local/bin`에 명령 세 개(`netwatch`, `iptime`, `netwatch-notify`)가 생기고, 로그인할 때마다 자동으로 켜지는 서비스가 등록돼요.

> `~/.local/bin`이 PATH에 없다면 `~/.zshrc`에 `export PATH="$HOME/.local/bin:$PATH"`를 한 줄 추가해 주세요.

### 2. 공유기 계정 저장하기

ipTIME 관리 화면(`http://192.168.0.1`)에 로그인할 때 쓰는 **관리자 아이디와 암호**를 키체인에 넣어요. 와이파이 비밀번호가 아니에요!

```bash
security add-generic-password -s iptime-admin -a <관리자_아이디> -w
```

엔터를 치면 암호를 물어봐요. 터미널 기록에도 암호가 남지 않아요.

> 관리자 계정이 기억 안 나면 공유기 뒷면 RESET 버튼을 10초 눌러 초기화한 뒤, `192.168.0.1`에 접속해서 새로 만들 수 있어요. 이때 와이파이 이름과 비밀번호도 초기화되니까, 예전과 똑같이 다시 설정하면 집 기기들이 그대로 다시 붙어요.

### 3. 우리 집 공유기 등록하기

**집 와이파이에 연결된 상태에서** 한 번 실행해요.

```bash
iptime pin
```

`집 공유기 MAC 등록: b0:..:..` 이 나오면 성공이에요. 이걸 해야 자동 복구가 켜져요.

### 4. (선택) 휴대폰 알림 받기

`~/.config/netwatch/config`를 열어서 `NOTIFY_TO`에 내 전화번호(`+8210...`)나 Apple ID 이메일을 적어요. Mac의 메시지 앱이 iMessage로 로그인돼 있어야 해요.

```bash
netwatch-notify --test
```

처음 한 번은 Mac 화면에 **"메시지를 제어하려고 합니다"** 창이 떠요. **허용**을 눌러 주세요. 휴대폰에 시험 메시지가 오면 끝이에요.

> 이걸 안 해 두면 집을 비운 사이에 복구돼도 알림이 조용히 실패해요. 비워 두면 Mac 알림 센터에만 떠요.

## 써 보기

| 하고 싶은 일 | 명령 |
|---|---|
| 무슨 일이 있었는지 보기 | `tail -20 ~/Library/Logs/netwatch.log` |
| 공유기 인터넷 상태 보기 | `iptime status` |
| 지금 당장 공유기 재부팅 | `iptime reboot` |
| 서비스가 돌고 있는지 확인 | `launchctl print gui/$(id -u)/local.netwatch \| grep state` |
| 잠깐 끄기 | `launchctl bootout gui/$(id -u)/local.netwatch` |
| 다시 켜기 | `launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/local.netwatch.plist` |

기록은 이렇게 읽으면 돼요.

- `끊김 시작: 상위장비=FAIL DNS=FAIL HTTP=000`: 끊긴 순간의 진단이에요. 상위장비는 공유기 앞의 통신사 장비인데, 설정에 `UPSTREAM`을 넣었을 때만 확인해요. 넣지 않았으면 `-`로 나와요.
- `복구됨: ..., 저절로 회복`: 30초 안에 혼자 돌아온 짧은 끊김이에요.
- `복구됨: ..., 자동 재부팅으로 복구`: 이 도구가 살린 경우예요.

### 설정 바꾸기

`~/.config/netwatch/config`에서 바꿀 수 있어요. 바꾼 뒤에는 서비스를 껐다 켜 주세요.

| 항목 | 기본값 | 뜻 |
|---|---|---|
| `ROUTER` | `192.168.0.1` | 공유기 주소 |
| `UPSTREAM` | 비어 있음 | 공유기 앞단 통신사 장비 주소. `iptime status`의 `gw=` 값을 넣으면 진단이 더 자세해져요 |
| `NOTIFY_TO` | 비어 있음 | iMessage 받을 주소 |
| `INTERVAL` | `10` | 몇 초마다 확인할지 |
| `REBOOT_AFTER` | `30` | 몇 초 끊기면 재부팅할지 |
| `REBOOT_COOLDOWN` | `1800` | 재부팅 후 몇 초 동안 다시 재부팅하지 않을지 |

## 궁금할 만한 것들

**맥북을 들고 카페에 가면요?**
아무것도 안 해요. 우리 집 공유기가 아니면 확인도, 기록도, 잠자기 방지도 하지 않아요.

**10초마다 확인하면 배터리나 네트워크에 부담 없나요?**
작은 ping 하나라 거의 티가 안 나요. 다만 집에 있는 동안은 Mac이 잠들지 않으니, 맥북이라면 전원을 꽂아 두는 걸 추천해요.

**맥북 덮개를 닫아도 되나요?**
외부 모니터와 전원이 연결된 클램쉘 모드면 괜찮아요. 그냥 덮개만 닫으면 macOS가 강제로 재워서 멈춰요.

**공유기 암호가 유출될 걱정은 없나요?**
암호는 키체인에만 있고, 공유기에 로그인할 때만 꺼내서 바로 보내요. 우리 집 공유기의 MAC이 맞을 때만 보내요. 다만 ipTIME 관리 화면 자체가 `http`라서 집 와이파이 안에서는 암호화되지 않은 채로 오가요. 이건 브라우저로 로그인할 때도 마찬가지예요.

**Mac을 새로 바꾸면요?**
마이그레이션 지원(Mac끼리 직접 옮기기, 또는 Time Machine 복원)으로 옮기면 설정과 키체인이 그대로 따라와요. 새 Mac에서는 `netwatch-notify --test`로 메시지 권한만 다시 받으면 돼요. iCloud만으로는 이런 파일들이 넘어가지 않아요.

**근본 원인은 뭔가요?**
집마다 달라서 단정하긴 어려워요. 만든 사람 집에서는 ipTIME은 "WAN 연결 정상"이라고 하는데, 실제로는 바로 앞의 통신사 장비에도 닿지 않는 상태였어요. 공유기를 재부팅하면 매번 바로 나았고요. 공유기와 통신사 장비 사이의 연결이 꼬이는 것으로 보여요. 랜선을 바꾸거나 통신사에 장비 점검을 요청하는 게 정공법이고, 이 도구는 그게 어려울 때 쓰는 현실적인 응급처치예요.

## 지우기

```bash
./uninstall.sh
```

서비스와 명령만 지워요. 설정(`~/.config/netwatch`), 기록(`~/Library/Logs/netwatch.log`), 키체인 계정은 남겨 두니까 필요 없으면 직접 지워 주세요.

```bash
rm -rf ~/.config/netwatch ~/Library/Logs/netwatch.log
security delete-generic-password -s iptime-admin
```

## 주의

공유기를 재부팅하는 도구예요. 재부팅하는 1~2분 동안은 집 안 모든 기기의 인터넷이 끊겨요. 직접 판단해서 써 주세요.
